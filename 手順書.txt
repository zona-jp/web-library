==========================================================
 ■ 日常の更新方法（これだけ覚えればOK）
==========================================================

 1. サイトを開く
 2. 右上の「EDIT」を押す
 3. メールアドレスとパスワードを入れてログイン
 4. 「NEW PROJECT」で追加、カードの編集ボタンで修正
 5. ★ 右上の黄色い「公開データを更新」を押す ★
 6. 「OK」を押したら完了。全員の画面に反映されます。

 ※ 5番を押さないと、他の人には反映されません。
 ※ GitHubを触る必要はありません。JSONを書く必要もありません。
 ※ スマートフォンからでも同じ手順で更新できます。


==========================================================
 ■ 公開・非公開の切り替え
==========================================================

 編集画面の「PUBLISHED」のチェックを外す → 「公開データを更新」

 チェックを外した成果物は、サーバー側で除外されるため
 閲覧者のブラウザには一切送られません（URLも説明文も見えません）。


==========================================================
 ■ 編集できる人を増やす / 減らす
==========================================================

 Supabase → Authentication → Users

  ・追加：「Add user」→「Create new user」
        メールアドレスとパスワードを入力し、
        必ず「Auto Confirm User」にチェックを入れる
  ・削除：一覧から対象ユーザーの「…」→ Delete user

 追加した人は、すぐにサイトからログインできます。

 ■ 困ったときは
==========================================================

【サイトに「共有データを取得できませんでした」と出る】
  → Supabaseが一時停止している可能性があります。
     Supabaseにログインし、プロジェクトを「Restore」してください。
     （無料プランは7日間アクセスがないと自動停止します）
     停止中も data.js の内容が表示されるため、サイトは白紙になりません。

【ログインできない】
  → Supabase → Authentication → Users で
     そのユーザーの「Confirmed」欄が空でないか確認してください。

【間違えて消してしまった / 前の状態に戻したい】
  → Supabase → SQL Editor で以下を実行し、履歴を確認します。

       select id, changed_at, changed_by, item_count
       from site_history order by id desc limit 20;

     戻したい行の id を確認し、次を実行します。

       update site_data
          set payload = (select payload from site_history where id = 【その id】)
        where id = 1;
